## 0. 目的 / スコープ

### 0.1 目的
- 全章の敵(雑魚妖魔・中ボス・章ボス・ラスボス)を**固有名詞・見た目・行動パターン・ステータス・ドロップ・出現ゾーン**まで確定し、B1(戦闘)/B2(成長曲線)/C5(マップ配置)/C6(ビルボード生成)が一意に参照できる図鑑を提供する。
- 第1章は縦スライス用に**フェーズ・ギミック単位で密度高く**確定する。第2〜5章は骨格＋ボス詳細を確定する。

### 0.2 スコープ
- **含む**: 雑魚妖魔の全体系統と第1章ぶんの具体個体、各章の中ボス・章ボス、ラスボス2段、ステータス仮値表、行動パターン(アクション戦闘前提)、ドロップ、出現ゾーン、推奨レベル帯。
- **含まない(他モジュール管轄)**: 攻撃の最終ダメージ計算式・被ダメ硬直フレーム(B1)、ドロップアイテムの効果詳細(B3/B4)、敵の出現テーブル抽選率の実装(B5)、ビルボードの解像度/命名規則(C6)、マップ上の正確な座標(C5)。本書はそれらが参照する**敵の真実**を定める。

### 0.3 設計前提(C1由来・厳守)
- 怪異は「**澱(おり)**」が形を得たもの。**下位(自然発生)/中位(名のある怨霊・付喪神=鎮魂可能)/上位(人為=呪詛体)/最上位(鬼門の主級)**の4格付けに全敵を分類する。
- 全敵は**五行(木火土金水)属性**を1つ持つ。相克(木→土→水→火→金→木)で弱点が決まる。B1の属性相性の根。
- 中位以上の一部は**鎮魂(ちんこん)**で救済でき、鎮魂すると**式神契約**や良ドロップに繋がる(=収集要素)。討伐(滅する)とドロップが変わる**二択**を持つ敵を明示する。

## 1. ステータス凡例 / 共通ルール

### 1.1 ステータス列定義(00b §2 正典語彙準拠)
> ステ語彙は00b §2に統一。MP相当は**気**、物理攻撃は**体**、防御は**護**、呪術攻撃は**術力**。HIT/EVAは廃止(被弾回避は手動i-frameのみ)。**第1章の敵ステ確定値は00b §5 再スケール表が「正」**。本書本文の旧数値は読み物としての目安であり、実装は00b §5を参照すること(食い違う場合は00bを正とする)。

| 列 | 意味(00b §2) | 単位/範囲の目安 |
|---|---|---|
| Lv | 推奨遭遇レベル帯 | 1〜40想定(v1は1〜8) |
| HP | 体力 | 雑魚20〜120 / ボス600〜8000 |
| 気 | 気(き)＝呪・特殊行動の発動源(旧MP) | 0〜400 |
| 体 | 物理攻撃の基礎火力(旧攻) | 雑魚6〜30 / ボス40〜220 |
| 護 | 被物理軽減(旧防) | 0〜120 |
| 速 | 行動速度(移動/攻撃前後隙の基準) | 1〜20(高いほど速い) |
| 術力 | 呪術攻撃力(属性ダメージ基準・旧呪力) | 0〜200 |
| 属 | 五行属性 | 木/火/土/金/水/特(無属性・特殊) |
| 格 | 怪異格付け | 下/中/上/最 |

### 1.2 行動パターン記法(アクション戦闘前提)
- **通常攻撃**: 接近/射撃の基本攻撃。隙(前後)を明記。
- **特殊技**: クールタイム(CT・秒)持ちの強行動。気消費が絡む場合は明記。
- **テレグラフ(予兆)**: プレイヤーが回避猶予を得る視覚予兆(光る/構える/床マーカー)。秒数を仮置き。
- **怒り/フェーズ移行**: HP閾値(%)でパターンが変わるボスに記載。

### 1.3 鎮魂/討伐の二択ルール
- 中位以上で「鎮魂可」の敵は、HPを削り切らず**「鎮魂窓(ちんこんまど)」**(後述ボスのギミック or 専用符使用)で鎮めると救済。鎮魂時は**穢が減る/契約or良ドロップ**、討伐時は**穢が微増/素材ドロップ**。プレイヤーの倫理選択を戦闘に落とす。

- **見た目(ビルボード)**: 端正な公卿装束の貴族。だが澱の力で右半身が黒く妖魔化し、片腕が鬼の腕に変容、衣から黒い触手状の澱が漏れる。優雅さと醜悪さの同居。冷たい微笑。
- **モチーフ**: 権力に魅入られた貴族・半人半妖。
- **役割/性格**: 政争の黒幕。怪異を政治の道具に使った張本人。傲慢で弁が立つ。
- **出現ゾーン**: 大内裏・玉座の間(ボスアリーナ)
- **推奨Lv**: 30〜33 / **属性**: 特(澱) / **格**: 上(人・鎮魂対象外)
- **弱点(相克準拠)**: なし(特ゆえ五行相性を受けない。00b §3)。高火力式神＋鎮魂の鈴で澱を剥がすと護が低下。
- **ステータス(仮・第5章はv1スコープ外。確定はB2再スケール時)**: HP4800 / 気300 / 体70 / 護40 / 速14 / 術力130 / 属特(澱) / 格上
- **行動パターン**: 通常＝鬼腕の薙ぎ。特殊A「澱の触手」(複数方向・拘束)。特殊B「祟りの呪詛」(操った虚ろ衛士を召喚)。特殊C「権謀の罠」(床に呪符トラップ設置)。怒り(35%)＝右半身の妖魔化が進み全行動高速化。**共闘**: 縹が参戦時は触手の拘束を解除/トドメ演出に絡む。
- **鎮魂可否**: 不可(人間の悪意は鎮魂できない=テーマの線引き)。撃破後、澱が剥がれ「ただの老いた人間」に戻り、玄冥に利用されていた事実が露見(玄冥が真の主犯)。
- **ドロップ**: 左大臣の笏(しゃく)(キーアイテム・進行用。00b §6の初期呪具「笏」`weap_shaku`とは別物の固有遺物) / 澱の特大魂石 / 「権の依代」

### 7.2 章ボス(ラスボス第一形態)：九尾の翁・玄冥(くびのおきな・げんめい)
- **格付け**: 最上位手前(人外化した呪術師)。
- **見た目(ビルボード)**: 痩せた老陰陽師。背後に九本の黒い狐火の尾が揺らめき、澱で出来た九尾の獣の影を背負う。眼は金色、口から呪を絶え間なく漏らす。禁忌派の黒い装束に呪符を貼り巡らせる。フェーズで尾の数だけ攻撃が増える。
- **モチーフ**: 九尾の狐・玉藻前・禁術師。
- **役割/性格**: 真の主犯。禁術探究と復讐の鬼。師・玄旨の旧友(C1伏線)。冷静で執念深い。
- **出現ゾーン**: 比叡の影山・鬼門の楔の祭壇(ボスアリーナ)
- **推奨Lv**: 34〜37 / **属性**: 特(全属性切替) / **格**: 上
- **弱点(相克準拠)**: 一定でない。フェーズ中に切り替わる属性に対し、その瞬間の防御属性へ相克で克つ攻撃属性を合わせると怯む(00b §3 相克マトリクスの動的適用)。
- **ステータス(仮・第5章はv1スコープ外。確定はB2再スケール時)**: HP6400 / 気400 / 体76 / 護42 / 速15 / 術力170 / 属特(全属性切替) / 格上
- **行動パターン(2フェーズ)**:
  - F1「九尾の呪法」＝尾ごとに異なる五行弾を撃ち分ける(属性ローテ=式神切替を要求)。「禁術の召喚」(精製澱から雑魚生成)。「呪詛の楔」(床固定罠)。
  - F2(HP45%)「澱喰らい」＝周囲の澱を吸って巨大化、九尾の獣影が実体化し物理攻撃を併用。「鬼門開きの儀」＝詠唱(完成すると大ダメージ全体・中断必須=結節点破壊ギミック)。属性切替への相克合わせはB1の五行読み合いの集大成(弱点詳細は上記)。
- **撃破後**: 玄冥は倒れるが、彼が解いた鬼門の封印は止まらず、積もった全澱が**鬼門の主**として顕現する=真ラスボスへ。
- **ドロップ**: 九尾の呪珠(キーアイテム) / 禁術の書(隠し式神「絲(いと)・白狐」契約の鍵。00b §4正典名=絲) / 全属性魂石

### 7.3 真ラスボス(最終形態)：鬼門の主・闇祇(きもんのあるじ・やみつおおかみ)
- **格付け**: 最上位(根源怪異)。C1テーゼ「妖魔は外から来ない＝人の業の集合体」の体現。
- **見た目(ビルボード)**: 都の全澱が凝った巨大な影の存在。固定の形を持たず、無数の人の顔・手・怨念が渦巻く黒い柱状の塊。中心に金色の単眼。背景に崩れゆく京音都と百鬼夜行。フェーズで「都を覆う巨大な影」→「凝縮した人型の鬼神」へ変容。最大級ビルボード＋複数レイヤー合成(影/顔群/単眼/オーラ)。
- **モチーフ**: 鬼門の災厄・百鬼の総体・人の業そのもの。
- **役割/性格**: 意思なき災厄でありながら、全ての怨念の声を発する。「人がいる限り我は還る」と語る。
- **出現ゾーン**: 鬼門の彼方(異界アリーナ・足場が澱の海に浮く崩れた都の残骸)
- **推奨Lv**: 38〜40 / **属性**: 特(無属性・全耐性高) / **格**: 最(鎮魂のみがクリア条件)
- **弱点(相克準拠)**: なし(無属性・五行相性を受けない。00b §3)。討伐不能=鎮魂専用。
- **ステータス(仮・終章はv1スコープ外。確定はB2再スケール時)**: HP8000 / 気500 / 体88 / 護50 / 速12 / 術力200 / 属特(無属性・全耐性高) / 格最
- **行動パターン(3フェーズ＋鎮魂フィナーレ)**:
  - F1「百鬼の渦」＝全方位の怨念弾、顔群からのレーザー(回転)、手による掴み。雑魚(夜行鬼)を無限湧き。
  - F2(HP60%)「業火と慟哭」＝アリーナ床が崩れ足場限定。広範囲の澱津波(全式神総出で耐える局面)。状態異常(穢の付与=プレイヤーの穢ゲージ強制上昇)。
  - F3(HP30%)「人型の顕現」＝鬼神形に凝縮し直接戦闘。最強の単体攻撃と全体呪詛。**ここで討伐に固執するとHPが減らない演出**(=滅しても澱は消えないテーゼ)。
  - **鎮魂フィナーレ(確定エンド)**: F3でHPを削り切れず膠着すると、師・玄旨/ライバル縹/全式神の力を結集し**「鎮魂の鈴」**を発動するイベントトリガー。プレイヤーは討つのでなく**都の澱を鎮魂**=浄化エンディング(C1正典の基本線)。穢の蓄積量でフィナーレ演出が分岐(穢低=完全浄化/穢高=辛勝・代償あり)。
- **鎮魂可否**: **鎮魂のみがクリア条件**(討伐不能＝テーマの仕掛け)。
- **ドロップ**: なし(クリア＝エンディング)。実績/隠し式神「絲(いと)・白狐」(00b §4正典名=絲)最終解放・クリアデータ継承要素(B2)。
