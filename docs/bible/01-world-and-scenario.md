## 1. 世界観

### 1.1 時代の空気
- **時代名**: 架空の平安朝。元号は「**天耀(てんよう)**」とする(史実連想を避けるための完全架空年号。裁定で確定)。物語は天耀三年・春から始まる。
- **基調**: 雅(みやび)の表層と、その裏で腐臭を放つ宮廷の闇。貴族は歌を詠み香を焚き、夜になれば**百鬼夜行(ひゃっきやぎょう)**が大路を練り歩く。光と闇が同じ都に同居する**和風ダークファンタジー**。
- **核心テーゼ(全編を貫く主題)**: 「**妖魔は外から来ない。人の心の澱(おり)が形を得たものである**」。怪異の根は常に人間の業(ごう)・怨み・欲にある。この一文が二層構造の黒幕設定と直結する。
- **トーン参照**: 夢枕獏『陰陽師』の妖しく静謐な雅 ＋ スマホ『陰陽師』の式神コレクション性 ＋ 和風ダークの退廃美。グロテスクよりも「美しくて怖い」を優先する。

### 1.2 舞台＝都「京音都(きょうおんと)」
- 架空の帝都。読み「**きょうおんと**」。実在の平安京を下敷きにした碁盤目状の都。
- **構造**: 南北に走る大路「**朱雀大路(すざくおおじ)**」が都を東西に二分する。北端に**大内裏(だいだいり)**(帝の御所と官庁)、その手前に陰陽寮系の施設群。
- **左京 / 右京の対比**(本作の地理的テーゼ):
  - **左京(東側)**＝栄える側。貴族の邸宅・市・寺社。表向き繁栄。
  - **右京(西側)**＝寂れた側。荒れた邸の廃墟・湿地・墓所。怪異の温床。光が左、闇が右。
- **垂直の対比**: 地上(都)／地下(穢れの溜まる水脈・古い塚)。怪異は地下から滲む。

### 1.3 陰陽寺(組織)
- **正式名**: 陰陽寺(おんみょうじ)。読みは「おんみょうじ」で確定(寺だが僧坊ではなく、陰陽道の専門官衙＋私塾を兼ねた施設という設定)。
- **役割**: 朝廷の**陰陽寮(おんみょうりょう)**の実働部隊にして、市井の怪異を鎮める現場機関。天文・暦・占い・式神術・怪異討伐を担う。
- **朝廷との関係**: 陰陽寮は朝廷の正規官庁。陰陽寺はその下にありながら、半ば独立した実戦集団。朝廷は怪異を「公にしたくない醜聞」として扱い、陰陽寺に**秘密裏の処理**を委ねる。よって陰陽寺は朝廷から「便利な掃除屋」として軽んじられ、予算も人も足りない。この**冷遇**が物語の政治的緊張を生む。
- **内部の派閥(確定・3派)**:
  1. **正道派(せいどうは)**: 主人公の師が率いる。怪異の根=人の心と捉え、討伐より鎮魂・救済を重んじる。少数派で冷遇。
  2. **実利派(じつりは)**: 朝廷に取り入り出世を狙う多数派。式神を兵器と見なし、効率的討伐と保身を優先。中盤の障害。
  3. **禁忌派(きんきは)**: 表向き解体された旧派閥。死者の操術・呪詛など禁術を扱った者たち。**裏の黒幕「闇の呪術結社」の源流**であり、生き残りが暗躍する。
- **陰陽寺の象徴物**: 「**鎮魂の鈴(ちんこんのすず)**」。怪異を祓うのでなく鎮めるための法具。正道派の理念の象徴で、終盤の鍵アイテム。

### 1.4 妖魔 / 怪異とは何か(発生原因の核心設定)
- **定義**: 「**澱(おり)**」と呼ぶ概念を核に据える。人の強い負の感情(怨み・嫉妬・執着・恐怖・後悔)が現世に**澱**として沈殿し、それが臨界に達すると形を得て**妖魔(怪異)**になる。
- **発生の二経路(確定)**:
  - **自然発生**: 個人の業から生まれる。怨霊・付喪神・地縛霊の類。小型。
  - **人為発生**: 何者かが意図的に澱を集め・煮詰めて怪異を**造る**。これが裏の黒幕の手口。大型・統制された妖魔。
- **核心の仕掛け**: 都の怪異が近年急増しているのは、(a)鬼門の楔が緩んでいる(物理) ＋ (b)誰かが澱を組織的に集めている(人為)の**二重原因**。プレイヤーは当初(a)だけだと思うが、真相は(b)が主因。これが二層構造の正典的根拠。
- **怪異の格付け(C3が参照)**:
  - **下位**: 雑霊・小鬼(ざこ)。澱の自然発生。
  - **中位**: 名のある怨霊・付喪神。固有の未練を持つ(=鎮魂で救済できる=正道派の戦い方)。
  - **上位**: 人為的に造られた**呪詛体(じゅそたい)**。澱を核に複数の怨念を縫合した人工怪異。各章のボス。
  - **最上位**: **鬼門の主(あるじ)**級。物語の根幹に関わる存在。

### 1.5 呪術体系(ルールの根)
後続のB1戦闘・B2成長が依拠する「**呪(まじない)の理(ことわり)**」を確定する。

- **大原則「五行(ごぎょう)」**: 木・火・土・金・水の五属性で世界が回る。式神・呪・妖魔すべてが五行属性を持つ。相生(そうじょう)＝強化、相克(そうこく)＝弱点。B1の属性相性はここに準拠。
  - 相生の輪: 木→火→土→金→水→木(生む)
  - 相克の輪: 木→土→水→火→金→木(克つ＝有利)
- **主人公の力の三系統(確定・B1/B2の技分類の根)**:
  1. **式(しき)＝式神術**: 紙の依代に魂を宿し、式神を召喚・使役する。本作の戦闘の中核。**主人公は直接殴らず、式神を操って戦う**(=式神オンリーの設計根拠)。
  2. **符(ふ)＝呪符術**: 札に呪を込め、攻撃・防御・補助を発動する消耗系リソース(=B3の消耗品・B1のスキルコスト基盤)。
  3. **呪(じゅ)＝詠唱呪法**: 主人公自身が詠唱する直接呪法(遠隔・直接近接ではない)。霊力「**気(き)**」を消費。式神不在時の自衛・状態異常付与。
- **リソース概念(B2が数値化する前提・名称確定)**:
  - **気(き)**: 霊力。呪・符・式神召喚/維持・鎮魂の発動源(行動資源)。旧称「呪力/MP」は全廃し気に一本化(00b §2)。
  - **縛(ばく)**: 式神を場に出している間の維持コスト枠。同時召喚数を縛が制限する。式神スロットの理屈。
  - **穢(けがれ)**: 禁術や澱に触れると溜まる堕落ゲージ。一定以上で主人公にデバフ。物語上の「人の業に呑まれる危うさ」を数値化(終盤の選択に絡む)。
- **式神契約のルール(C2/C3が参照)**: 式神は「**真名(まな)**」を知り、依代(紙・面・骨片など)に縛ることで使役できる。強い式神ほど契約に代償(穢の蓄積・条件付き)を要する。**式神は倒した妖魔を鎮魂し契約する**ことで増える(=収集要素の正典的根拠)。
- **禁術(きんじゅつ)**: 死者の操術・呪詛・澱の精製。使えば強大だが穢が急増する。裏の黒幕が用いる体系。主人公が終盤に「使うか否か」を問われる。

## 2. メインストーリー(全5章アーク)

> 表(妖魔の脅威)と裏(人間の陰謀)が章ごとに少しずつ繋がる。プレイヤーの認識は「怪異退治もの」→「都の異変の謎」→「宮廷の陰謀」→「禁術結社の真相」→「鬼門と人の業の対決」と推移する。

### 全体プロット要約(ネタバレ＝開発者向け真相)
都の怪異急増の表向きの原因は「鬼門の楔の緩み」。だが真因は、左大臣**藤宮 影道(ふじみや かげみち)**が政敵失脚と権力簒奪のため、地下に潜った禁忌派の末裔である呪術師**九尾(くび)の翁・玄冥(げんめい)**と結託し、都中の澱を組織的に集めて怪異を造り、政敵に「祟り」を被せていたから。集めた澱の最終目的は、鬼門の封印を意図的に破り、**鬼門の主**を呼び出して都の支配権を握ること。主人公は表の妖魔退治を通じてこの陰謀に近づき、最終的に「妖魔を生むのは人の業」という核心テーゼに直面し、黒幕を討つだけでなく都の澱そのものを鎮魂するに至る。

### 第1章「霞ヶ辻の怪(かすみがつじのけ)」 ※縦スライス・最重要
- **タイトル**: 霞ヶ辻の怪
- **舞台(場所)**: 門前町・霞ヶ辻(ハブ) / 右京・西院の枯野(フィールド1) / 羅城門・地下(ダンジョン1)
- **表の脅威(妖魔)**: 門前町で子どもや旅人が次々と「神隠し」に遭う。原因は枯野に巣食う中位怨霊と、羅城門地下に湧く小鬼の群れ。
- **中ボス**: **泥眼(でいがん)の女**。枯野の廃邸に憑く中位怨霊。生前、約束を破られ捨てられた女。鎮魂で救済可能(=正道派の戦い方のチュートリアル兼任)。
- **章ボス**: **羅城門の喰い鬼(くいおに)**。羅城門地下に巣食う上位怪異。神隠しの正体。**ただし不自然に強く統制が取れており、自然発生ではない=人為の臭いを初めて提示**。倒した後、その核から「精製された澱の塊」が出てくる(=黒幕の存在を示す最初の物証)。
- **明らかになる事実**: 怪異が「誰かに造られている」可能性。神隠しの裏で、ある下級貴族の屋敷から不審な符が出回っていたこと(=陰謀への最初の糸口)。黒幕の名はまだ出ない。
- **主人公の成長点**: 式神術の基礎を習得。最初の式神「**烏天狗(からすてんぐ)・玄(げん)**」と契約。鎮魂と討伐の違いを学ぶ。師の理念に触れる。
- **v1縦スライス要素(このモジュールが保証する内容)**: 霞ヶ辻(町＋ショップ＋NPC数名＋クエスト数本) ／ 枯野(フィールド1) ／ 羅城門地下(ダンジョン1) ／ コア戦闘(主人公＋**使役式神は玄1体のみ**) ／ ボス1(喰い鬼) ／ セーブ。物語的には「怪異退治→人為の疑い提示→引き(黒幕への糸口)」で1本完結＋続編フック。
  - 裁定: **v1使役式神=玄のみ**。燼は第2章契約でありv1は登場演出のみ(使役不可)。縛=v1は1枠固定(同時召喚1体)。複数枠はv2。

### 第2章「鳥辺野の喪(とりべののも)」
- **舞台**: 鳥辺野(葬送地) / 東市 / 五条堀川
- **表の脅威**: 葬送地から死者が起き上がる怪異(動死体＝禁術の臭い)。疫病めいた澱の拡散。
- **中ボス**: **骨喰(ほねばみ)の獄卒**。塚を守る付喪神化した古具足。
- **章ボス**: **喪(も)の塗仏(ぬりぼとけ)**。多数の死者の澱を縫合した人為怪異。第1章で見た「精製された澱」と同質と判明。
- **明らかになる事実**: 怪異の人為発生を確信。**禁忌派の生き残りによる「澱の精製」術が裏で動いている**こと。ライバル陰陽師**藤宮 縹(ふじみや はなだ)**が初登場し、彼が左大臣家の縁者だと示される(=後の伏線)。
- **主人公の成長点**: 二体目の式神(火属性「**火車(かしゃ)・燼(じん)**」)契約。穢の概念を体験(禁術の現場に触れ穢が初めて溜まる)。

### 第3章「夜御殿の囁き(よんのおとどのささやき)」
- **舞台**: 大内裏・夜御殿(宮廷) / 朱雀大路(夜)
- **表の脅威**: 宮中で要人が次々と「祟り」で倒れる。怪異が政治の道具として使われ始める。
- **中ボス**: **生霊(いきりょう)の女御(にょうご)**。嫉妬から生霊を飛ばす宮廷女性(鎮魂可能・人の業の哀切を描く山場)。
- **章ボス**: **囁(ささや)きの面(おもて)**。澱を媒介に人を操る人工呪具型怪異。これを操っていた者の影が見える。
- **明らかになる事実**: **裏の黒幕が宮廷の権力者であること**が露見。「祟り」の被害者がすべて左大臣**藤宮 影道**の政敵だったと判明=政争の道具としての怪異。だが影道は表向き完璧な紳士で証拠がない。陰陽寺・実利派は影道に取り込まれており、主人公の捜査を妨害する。
- **主人公の成長点**: 三体目の式神(水属性「**濡女(ぬれおんな)・澪(みお)**」)。組織内政治の壁に直面し、孤立しながら真実を追う覚悟を得る。

### 第4章「神泉苑の龍(しんせんえんのりゅう)」
- **舞台**: 神泉苑(禁苑) / 右京の地下水脈
- **表の脅威**: 都の地下水脈に澱が逆流し、聖地・神泉苑の守護龍が穢れて暴走。大規模水害級の怪異。
- **中ボス**: **泥龍(でいりゅう)の眷属**。穢れた龍の分身。
- **章ボス**: **穢れ龍・濁(にごり)**。神泉苑の守護龍が澱に呑まれた姿。**浄化(鎮魂)して救うか、討つかの選択が初めて発生**(穢ゲージと絡む分岐)。
- **明らかになる事実**: 澱を組織的に集める総元締めが、禁忌派の長老**玄冥(げんめい)**だと判明。玄冥と左大臣**影道**の結託の物証を入手。目的が「鬼門を意図的に破ること」だと察知する。ライバル**縹**が、左大臣家の暗部を知り苦悩する姿が描かれる(=寝返りの伏線)。
- **主人公の成長点**: 四体目の式神(土属性の重撃役「**土蜘蛛(つちぐも)・厳(いわお)**」候補)。穢が高まり、自身が業に呑まれかける危機を経験。師の真意(後述)に触れる。

### 第5章「鬼門・天耀の闇(きもん・てんようのやみ)」 ※終章統合
- **舞台**: 比叡の影山・鬼門の楔 / 大内裏(クライマックス) / 鬼門の彼方(最終決戦の異界)
- **表の脅威**: 左大臣**影道**と玄冥が鬼門の楔を破壊し、**鬼門の主**を顕現させる。都全体が百鬼夜行に呑まれる終末的状況。
- **中ボス**: **左大臣・藤宮 影道**(人間の黒幕)。澱の力で半ば妖魔化した姿で対峙。ここでライバル**縹**が主人公側に寝返り共闘(条件付き)。
- **章ボス(ラスボス・第一形態)**: **九尾の翁・玄冥**。禁忌派最後の長老。澱を喰らい人外と化した呪術師。
- **真ラスボス(最終形態)**: **鬼門の主・闇祇(やみつおおかみ・読みは「やみつおおかみ」で裁定確定)**。鬼門の彼方から呼ばれた、都に積もった全ての澱の集合体たる根源怪異。「人の業そのもの」を体現する存在。
- **明らかになる真相(全開示)**: 怪異急増は鬼門の緩み＋人為の二重原因で、主因は人為。黒幕は左大臣**影道**(政争の動機)と玄冥(禁術の探究と復讐の動機)。二人の利害が一致して結託した。最終的に「妖魔を倒しても都の澱が消えなければまた生まれる」と判明し、主人公は陰陽寺の「**鎮魂の鈴**」と全式神の力を結集し、闇祇を討つのでなく**鎮魂**して都の澱を浄化する(正道派テーゼの成就)。
- **主人公の成長点**: 穢に呑まれず人の業を「祓う」のでなく「受け止め鎮める」境地へ。師の遺志を継ぐ。
- **師の真相(伏線回収)**: 主人公の師**安倍 晴明(あべの せいめい)系譜の老陰陽師「賀茂 玄旨(かもの げんし)」**(下記名簿参照)は、かつて禁忌派にいた玄冥の旧友であり、過去に澱の研究を共にした過去を持つ。師が正道派を貫くのは、その贖罪。終章で師は主人公を守り命を落とす(またはその一歩手前)展開で物語に重みを与える。

## 3. 二層の黒幕(確定・最終真相)

### 3.1 表層(妖魔/怪異の脅威)
- **見かけの原因**: 比叡・鬼門の楔の緩みによる怪異の自然増加。
- **プレイヤーの初期認識**: 「都に怪異が増えた、退治しよう」。第1章はこの認識で進む。
- **役割**: 各章のボス＝目に見える脅威。だが章を追うごとに「統制された妖魔=人為」の証拠が積み上がる。

### 3.2 裏層(人間の陰謀)
- **正体①(政治の黒幕)**: **左大臣・藤宮 影道(ふじみや かげみち)**。
  - **動機**: 摂関の座と都の実権簒奪。政敵を「祟り」で失脚・抹殺するため怪異を利用。表向きは温厚で人望ある名臣を演じる。
  - **手口**: 玄冥に澱を集めさせ、人工怪異を政敵に差し向ける。陰陽寺・実利派を金と地位で抱き込み捜査を妨害。
- **正体②(呪術の黒幕)**: **九尾の翁・玄冥(くびのおきな・げんめい)**。
  - **動機(二重)**: (a)禁術=澱の精製術を極める純粋な探究欲。(b)かつて禁忌派を切り捨て解体した朝廷と陰陽寺正道派(=師・玄旨)への復讐。
  - **手口**: 都中の澱を「精製」して人工怪異を量産。最終目的は鬼門を破り**鬼門の主**を呼び、自らが人外の高みへ至ること。影道の政治力は手段に過ぎない。
- **繋がり**: 影道(権力が欲しい) × 玄冥(術の素材＝澱と保護が欲しい)の利害一致による共犯。影道は玄冥を道具と思い、玄冥は影道を踏み台と思っている。**互いに利用し合う不安定な同盟**で、終盤に決裂する(=ボスを2段構成にできる)。
- **最終真相(核心テーゼの成就)**: 黒幕を倒しても、都に積もった**澱(=人々の業)**が残る限り怪異は生まれ続ける。真の敵は「人の心の澱」そのもの＝**鬼門の主・闇祇**として顕現する。よってクライマックスは「悪人退治」ではなく「都全体の鎮魂」へ昇華する。これが本作のテーマ「妖魔は外から来ない」の回収。

- **妖魔 / 怪異(ようま / かいい)**: 澱が形を得たもの。自然発生と人為発生がある。

- **式 / 式神(しき / しきがみ)**: 真名を依代に縛り使役する使い魔。本作の戦闘中核。

- **鎮魂(ちんこん)**: 怪異を祓い滅するのでなく、未練を解き鎮め救済する技法。正道派の理念であり、式神契約と浄化エンディングの鍵。
- **五行(ごぎょう)**: 木火土金水の五属性。相生・相克の戦闘相性の根。
- **気(き)**: 霊力。呪・符・式神召喚/維持・鎮魂の発動源(行動資源・旧MP相当を統合)。
- **縛(ばく)**: 式神を場に維持するコスト枠。同時召喚数の制限。
- **穢(けがれ)**: 禁術や澱に触れて溜まる堕落ゲージ。終盤の選択・分岐に絡む。
- **禁術(きんじゅつ)**: 死者の操術・呪詛・澱の精製。強大だが穢を急増させる。禁忌派・玄冥の体系。
- **鎮魂の鈴(ちんこんのすず)**: 陰陽寺正道派の象徴法具。終盤、都の澱を鎮める切り札。
