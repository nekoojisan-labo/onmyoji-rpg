## B1 戦闘システム(アクション)

### B1.1 目的 / スコープ

- 主人公(陰陽師)が前線に立ち、**式神を召喚・切替**しながら妖魔とリアルタイムで戦うアクション戦闘を定義する。
- **主人公は式神オンリー＝直接近接で殴らない**。手段は **符(遠隔の基本攻撃)＋呪(詠唱スキル・気消費)＋式神召喚/切替/指揮＋鎮魂** のみ(裁定・00b §2.5)。火力・タンク・搦め手は式神が担う。式神が事実上の「手駒/パーティ」。
- v1スコープ: 符投げ・回避・呪術スキル2種・札(消費アイテム)・式神召喚/切替・**鎮魂コマンド**・敵AI3パターン・状態異常・シームレスエンカウント。**縛(同時召喚)はv1=1枠固定(同時顕現1体)**。複数枠/複数式神の同時運用やパッシブ連携はv2送り(open question参照)。
- 非スコープ: 通信/同期、味方人間NPCの戦闘参加、ターン制要素、主人公の直接近接コンボ(撤回済み)。

### B1.2 操作と手触り

入力はキーボード主体(ゲームパッド対応はv2)。判定はすべてフレーム駆動(60fps基準、`deltaTime`正規化)。

入力⇄ホットバー(B7・8スロット)の対応は 00b §7.4 が正典。本表の既定キーはそれと一致させる。

手触り設計原則(デウス・コード教訓の踏襲):
- 符・回避・呪術は**先行入力バッファ0.15s**を持ち、モーション終端で次入力を受ける(入力の取りこぼし防止)。
- ヒット時に**ヒットストップ**(対象とプレイヤーを2〜4フレーム停止)＋軽い画面シェイク。重撃ほど長い。
- 被弾時に**0.5sのハイパーアーマー無し短硬直**＋ノックバック(0.3〜0.8unit)。
- 移動・攻撃のスプライト方向は**4方向**(down/left/right/up・右=左反転flipX。8方向は撤回。後述B1.9の制約に従う)。

### B1.3 式神システム

「召喚 → 自律行動 + 指示 → 切替 → 帰還」のループ。式神は**主人公とは別エンティティ**で、独自HP/AIを持つ。

- **縛(編成スロット)**: **v1は1枠固定**(同時召喚1体＝`shikiSlots[0]`のみ)。複数枠（術式盤に複数セット）はv2(open question)。理由=スプライト/AI/判定の同時負荷とバランス制御の単純化。
- **同時召喚数**: v1は**同時に1体のみ顕現**(常時1体運用 + 切替)。複数同時顕現はv2(open question)。
- **召喚コスト**: 召喚時に**気**を消費し、顕現中は**維持コスト(毎秒)**が発生。気が0になると式神は強制帰還。
- **切替**: `E`で編成内を順送り(v1は1体のため実質無効、v2で複数枠時に機能)。切替時、退場する式神のHPは保持(再召喚で同HP)。**帰還中は気が自然回復(回復ボーナス)**。
- **式神HP**: 0になると「破符(撃破)」。破符した式神は当該戦闘中は再召喚不可。戦闘終了 or 拠点で全快。
- **式神の自律AI**: 主人公の弱ロック対象を優先攻撃。指示(R)で集合/攻撃方向を上書き。

式神の役割(クラス)・五行・基礎ステ・主要技・成長レートは **00b §4 式神マスター(6体・正典)が唯一の正本**。本書では役割と立ち回り設計のみを示し、ステ表は持たない(旧B2別系統名 火喰鬼/土塊狗/紙縒狐/護童子/影鵺 は全廃)。

| 役割 | 立ち回り | 正典式神(00b §4) | 五行 | v1可否 |
|---|---|---|---|---|
| 速・牽制・基本アタッカー | 高速・牽制・突進 | **玄(げん・烏天狗)** | 木/風 | ✅ v1使役可 |
| 火力アタッカー | 高火力近接・範囲炎 | **燼(じん・火車)** | 火 | 第2章契約(v1は登場演出のみ) |
| 回復・補助 | 治癒/穢軽減/耐性付与 | **澪(みお・濡女)** | 水 | 第3章契約 |
| 重撃・盾 | ヘイト取得・防御・重撃 | **厳(いわお・土蜘蛛)** | 土 | 第4章契約 |
| 貫通・対呪 | 護貫通・敵バフ/呪詛解除 | **煌(こう・金鵄)** | 金 | 後半(第5章前後) |
| 隠し・条件付き | 混乱付与・全体浄化 | **絲(いと・白狐)** | 水(特殊) | スコープ外(v1はフラグ予約のみ) |

- **v1使役式神=玄のみ**(裁定)。他5体の契約は章進行で解禁(00b §4)。
- 五行相性は 00b §3 相性表が唯一基準(相生×0.85／相克×1.25・同/無関係×1.0)。本書末尾B1.13の行列は00b §3の写しであり、値の正本は00b。玄の風は演出/牽制属性で倍率非関与(五行上は「木」として計算)。

### B1.4 気(行動資源)とクールダウン

- 主人公の行動資源は**気(き)**に一本化(旧「呪力/MP/JURYOKU」表記は全廃・00b §2)。式神召喚・維持・呪術スキル・鎮魂がこれを消費。
- **符投げ(基本攻撃)は気消費なし**(常時択を確保)。
- 気の自然回復: 非召喚時 `+6/s`、召喚維持中 `+2/s`、回避/被弾直後1sは回復停止。**穢が軽い穢(40〜69)以上で気回復速度−25%**(00b §2.3)。
- 呪術は**気消費 + 個別クールダウン**の二重制限(連打防止 + 資源管理)。
- 召喚/維持の正典コストは式神ごとに 00b §4(召喚25・維持2〜4/s)を参照。下表は資源/CDの設計仮値。

| 資源/CD項目 | 仮値 |
|---|---|
| 初期最大気 | 100 |
| 式神召喚コスト(初回顕現) | 25(00b §4・全式神共通) |
| 式神維持コスト | 役割により 2〜4/s(00b §4・例 厳=2, 玄/澪=3, 燼=4) |
| 呪術スキル消費 | 12〜30(スキル依存) |
| 呪術スキルCD | 3〜12s(スキル依存) |
| 鎮魂チャネル消費 | 気消費(約1.5sチャネル中・00b §2.4) |
| 回避CD | 0.6s(資源消費なし) |
| 札(アイテム)CD | 共通グローバルCD 1.0s |

### B1.5 敵AI(索敵 / 接近 / 攻撃パターン)

ステートマシン: `IDLE → ALERT → CHASE → ATTACK → RECOVER → (RETREAT/RESET)`。

- **索敵(IDLE→ALERT)**: 視界 = 前方扇形(半径 `sightRange`、角度120°) + 全方位の近接気配(半径 `senseRange`)。プレイヤー or 顕現中式神を検知。
- **接近(CHASE)**: 検知対象のうち**ヘイト最大**へ移動。守式神の挑発でヘイトを固定可能。経路は簡易(直進 + 障害物回避レイ)。
- **攻撃(ATTACK)**: 攻撃レンジ内で攻撃モーション。各敵は1〜3種のパターンを持つ:
  - パターンA「直接打撃」: 前方近接、予兆0.4s→判定0.15s。
  - パターンB「飛び道具」: 怨念弾を直線発射、予兆0.6s。
  - パターンC「範囲呪」: 自身中心 or 着弾円の範囲(AoE)、予兆0.8s(回避猶予を必ず確保)。
- **予兆(テレグラフ)必須**: 全攻撃に地面デカール or ビルボード発光の予兆を表示(回避ゲームの公平性担保)。
- **RECOVER**: 攻撃後の隙(0.3〜0.8s)。**ここが反撃窓**。
- **RESET**: 対象がリーシュ半径(=スポーン地点から `leashRange=20unit`)を超えたら帰還・HP全快。

ボスAIは上記に**フェーズ遷移**(HP閾値で攻撃テーブル切替)を追加。**第1章章ボス=羅城門の喰い鬼**(らじょうもんのくいおに・旧「黒鉄不動」は廃止)は2フェーズ(F1=火→F2=特・C3／00b §5連携)。F2の弱点窓は**玄(木/風)or 符/呪で開く**(澪は要求しない・裁定)。第1章雑魚は03の5種(鬼火童子/迷い人魂/化け狸・腹鼓/餓ち餓ち/古傘鬼)・中ボスは泥眼の女(00b §5)。

### B1.6 当たり判定方式(2.5D)

3D空間だが**ゲームプレイ判定は地表XZ平面の2D**で行う(高さYは演出・ジャンプ無しのため判定除外)。深度ソートはz座標で自動(描画はビルボード)。

- **エンティティ**: 中心点 + 半径の**円(カプセル簡略)**。`{ x, z, radius }`。
- **通常攻撃/近接**: プレイヤー前方の**扇形(中心角・半径)**。`hit = (距離 ≤ range) && (角度差 ≤ arc/2)`。
- **飛び道具**: 移動する小円。毎フレーム対象円と距離判定。命中で消滅。
- **範囲呪(AoE)**: 着弾点中心の円、または直線(矩形を線分+幅で近似)。
- **回避i-frame**: 無敵時間中は全被弾判定をスキップ。
- 判定はすべて**距離の二乗**で比較(sqrt回避、`dx*dx+dz*dz ≤ r*r`)。
- 1フレームの被弾は**同一攻撃IDにつき1回**(多段ヒット防止に攻撃インスタンスIDを記録)。

### B1.7 ダメージ計算式(具体)

正典のダメージ式は **00b §2.2 が正本**。攻撃ステは物理=**体**・呪術=**術力**に分離。減算と除算のハイブリッドで防御の効きを安定させる:

```
物理基礎 = 体   × skillMul        // 符・物理技
呪術基礎 = 術力 × skillMul        // 呪・属性技
防御後   = 基礎 × (100 / (100 + 護))
属性後   = 防御後 × elemMul        // 0.85 / 1.0 / 1.25(00b §3)
会心後   = 属性後 × (会心なら critMul else 1.0)   // 会心率=CRT%
最終     = max(1, floor(会心後 × random(0.95, 1.05)))   // ±5%乱数・最低1保証
```

- `skillMul`: 符(基本遠隔)=1.0、呪術=1.4〜3.0、式神技=役割依存。
- `100/(100+護)`: 護100で被ダメ半減、護300で1/4。HP/体のインフレに対して防御が破綻しない。
- **会心(クリティカル)**: 発生率 `CRT率`(本体ステ・基礎5%)、倍率 `critMul`(装備由来・基礎1.5)。所有の正典は00b §2.1。
- **命中/回避は廃止**(HIT/EVA全廃・00b §2.1)。命中は100%固定とし、被弾回避は**プレイヤーの手動i-frameのみ**で支配(アクション性担保)。ミス演出は無し。
- **状態異常付与判定**: `applyChance = baseChance × (1 - 対象の呪抵抗/100)`(呪抵抗=気からの派生値・独立ステではない)。

例(第1章 主人公Lv5, 体40, skillMul=2.0, 対象 護30, 属性有利1.25, 会心無し):
`40×2.0=80 → 80×(100/130)=61.5 → ×1.25=76.9 → floor(×1.0乱数中央)=76`。

### B1.8 状態異常(和風)

最大同時付与数の制限は無し(重複は仕様別に規定)。各異常はターン制でなく**実時間の持続秒数**で管理。

解除に使う札の正典名は 00b §6.1(浄め札=状態異常1種解除＋穢−5／解呪札=呪詛・封 解除＋呪抵抗一時+20)に統一。旧「解毒札/破魔札/退魔札」は廃止し、本表でも統合名へ寄せる。

| 状態異常 | 和名 | 効果(仮値) | 持続 | 解除 |
|---|---|---|---|---|
| 毒(継続dmg) | 蝕(むしばみ) | 最大HPの3%/sを継続削り | 6s | 時間 / 浄め札 |
| 出血(継続dmg) | 流血(りゅうけつ) | 固定8/s、移動で加速 | 5s | 時間 |
| 麻痺(行動阻害) | 痺(しびれ) | 行動不可、被ダメ+10% | 2s | 時間 / 浄め札 |
| 封(スキル封印) | 封(ふう) | 呪術スキル・召喚使用不可 | 4s | 時間 / 解呪札 |
| 呪(弱体) | 呪詛(じゅそ) | 護-30%・回復量半減 | 8s | 解呪札 / 拠点 |
| 鈍(減速) | 鈍足(どんそく) | 移動・攻撃速度-40% | 4s | 時間 |
| 畏(行動鈍化) | 畏縮(いしゅく) | 与ダメ-25%、確率で行動キャンセル | 5s | 時間 |
| 凍(停止) | 縛(しばり) | 完全停止(被ダメで早期解除) | 1.5s | 被ダメ / 時間 |

- プレイヤーも敵も同じ異常システムを使用。プレイヤーは**呪抵抗(気からの派生値)**で付与率を下げる(00b §2.1)。
- 異常アイコンはHUD(B7)に残り時間ゲージ付きで表示。
- 蓄積型(ゲージが溜まって発症)はv1では採用せず**即時付与**(単純化)。蓄積型はv2 open question。

### B1.9 スプライト / ビルボード方向設計(教訓直視)

デウス・コードでスプライト一貫性が最大の苦労だった点を直視し、方向数を**設計時に固定**する。**方向数=4(down/left/right/up)に統一**(裁定。8方向は撤回。**右=左の反転flipX**で生成し別テクスチャは持たない):

- **主人公**: 4方向 × (待機/歩行/符投げ/回避/被弾/詠唱/召喚/鎮魂) アニメ。フレーム数は1アニメ4〜8。直接近接の3段コンボアニメは不要(撤回)。
- **式神・敵**: 同じく**4方向**(down/left/right/up・右=左反転)で制作コストを管理。ボスのみ専用演出を追加可。
- ビルボードは常にカメラへY軸ヤウ正対(オルソ・仰角30°固定なので奥行きで縮まない)。「見かけの向き」はスプライトのフレーム選択(右は左の反転)で表現。
- 命名規則はC6パイプラインに準拠(`{char}_{action}_{dir}_{frame}.png`・dir∈{down,left,right,up})。本モジュールは**必要な方向数・アクション一覧を確定する責務**を持ち、量産はC6。

### B1.10 エンカウント方式

- **シームレス・シンボルエンカウント**: 敵は**同一シーン内にシンボル(ビルボード)として常駐**(ランダムエンカウント無し・マップ遷移無し)。battleはfield内のサブ状態(裁定)。
- **同一シーン内のシンボル接触** or 索敵で**その場で戦闘開始**(別画面ロード無し、BGMだけ戦闘曲へクロスフェード)。
- エリア内の全敵を撃破すると「浄域」表示(クエスト/扉解放のトリガにC5/B5連携)。
- 一部エリアは**敵リポップ**(離脱・再入場で復活、`respawnDelay=120s`)。経験値稼ぎ動線を確保。
- ボスは専用トリガ領域進入で開戦、撤退不可(境界封鎖の結界演出)。

### B1.11 戦闘ループ(毎フレーム処理順序)

1. 入力収集(先行入力バッファ反映)
2. プレイヤー状態更新(移動/アクション/i-frame/異常)

## B2 パラメータ / 成長

### B2.1 目的 / スコープ

- 主人公と式神のステータス・経験値・レベル成長・装備補正・敵ステータステーブル・ドロップ/報酬を定義する。
- v1スコープ: 主人公Lv1〜20想定(第1章で〜Lv8程度)、式神は捕獲時Lvで成長、第1章の敵テーブル数体ぶんの具体値。

### B2.2 ステータス定義(確定)

ステ定義の正典は **00b §2.1(正典8項目)**。MP相当は**気**に一本化、攻撃は物理=**体**・呪術=**術力**に分離、**HIT/EVAは廃止**、会心は **CRT率(本体)＋critMul(装備由来)** に分解。

| ステ | 正典和名 | 略号 | 旧称(廃止) | 意味 | 影響先 |
|---|---|---|---|---|---|
| 体力 | HP | HP | — | 最大HP | 生存 |
| 気 | 気(き) | 気 | 呪力/MP/JURYOKU | 行動資源(召喚・維持・呪術・鎮魂) | スキル/召喚/鎮魂/呪抵抗派生 |
| 体 | 体(たい) | 体 | 攻/ATK(物理分) | 物理攻撃の基礎火力 | 物理ダメージ式の基礎 |
| 護 | 護(ご) | 護 | 防/DEF | 被ダメ軽減 | `100/(100+護)` |
| 術力 | 術力(じゅつりき) | 術 | 呪力(攻)/MAG | 呪術スキル威力倍率 | 呪術ダメージ式の基礎・係数乗算 |
| 速 | 速(そく) | 速 | SPD | 移動速度・攻撃後隙短縮・CD補正 | 移動/隙/CD |
| CRT率 | 会心率 | CRT | critRate | 会心発生率(%・所有=本ステ) | 会心判定 |
| critMul | 会心倍率 | critMul | — | 会心時ダメージ倍率(所有=装備由来) | 会心ダメージ |

- **廃止**: HIT(命中)/ EVA(回避)＝命中100%固定・手動i-frame支配。呪抵抗RESは独立ステではなく**気からの派生値**としてのみ存続。
- **派生**: `移動速度 = baseMoveSpeed × (1 + 速/200)`、`呪抵抗 = floor(気/10) + 装備`、`攻撃後隙 = base × (1 - 速/300)`。
- ステは「**素値(レベル成長) + 装備補正 + バフ/穢デバフ**」の合算で実効値を算出。素値はimmutableに保持し、実効値は都度計算(コーディング規約: 元を変更せず新オブジェクト)。

### B2.3 主人公 レベル / EXP曲線

EXP必要量は緩い指数で設計(中編・5〜6章で頭打ちしない):

```
nextExp(L) = floor(50 × L^1.5 + 20 × L)
累計到達EXP(L) = Σ nextExp(1..L-1)
```

列名は00b §2.1の正典ステ(気/体/護/術力)へ統一。

| Lv | 次Lvまで必要EXP | HP | 気 | 体 | 護 | 速 | 術力 |
|---|---|---|---|---|---|---|---|
| 1 | 70 | 80 | 60 | 12 | 8 | 10 | 10 |
| 2 | 113 | 92 | 66 | 15 | 10 | 11 | 12 |
| 3 | 169 | 104 | 72 | 18 | 12 | 12 | 14 |
| 5 | 320 | 130 | 86 | 26 | 17 | 14 | 19 |
| 8 | 622 | 172 | 110 | 40 | 26 | 17 | 28 |
| 10 | 866 | 200 | 128 | 50 | 32 | 19 | 34 |
| 15 | 1623 | 275 | 175 | 76 | 48 | 24 | 50 |
| 20 | 2598 | 350 | 224 | 104 | 65 | 29 | 67 |

- 成長は**1Lv毎の固定増分テーブル**(キャラ職=陰陽師は1種なので曲線は1本、ランダム成長なし=デバッグ容易性優先)。
- HIT/EVAは廃止(命中100%固定)。会心は **CRT率基礎=5%・Lv緩成長 `5 + 装備`**、**critMul基礎=1.5(装備由来)**。呪抵抗は派生(`floor(気/10)+装備`)。
- レベルアップで**HP/気 全快 + 軽い演出**(B7 HUD連携)。

### B2.4 式神の成長

- 式神は**育つ(レベル制)**。ただし主人公とは別経験値プール。
- **獲得**: 戦闘終了時、顕現していた式神に主人公獲得EXPの**70%を分配**(顕現時間に比例しない一律分配で単純化)。破符した式神も戦闘完遂時に分配対象。
- **成長式**: 式神は役割ごとの**成長レート(growthRate)**を持ち、`ステ(L) = 基礎ステ × (1 + (L-1) × growthRate)`。
- レベル上限: 式神は**主人公Lv + 2**を上限(主人公が育つほど式神も伸びる、逆転防止)。
- **進化/覚醒**はv1非対応(open question)。式神は固定五行・固定役割。

**式神の基礎ステ・成長レート・召喚/維持コスト・主要技は 00b §4 式神マスター(6体・正典 玄/燼/澪/厳/煌/絲)が唯一の正本**。旧B2の別系統名(火喰鬼/土塊狗/紙縒狐/護童子/影鵺)と自前ステ表は全廃し、本書は重複表を持たない。

00b §4 から要点のみ再掲(値は00bが正):
- 成長式: `ステ(L) = 基礎 × (1 + (L−1) × growthRate)`。役割別growthRate(HP/体/護/速/術力)＝速型(玄)/攻型(燼)/補型(澪)/守型(厳)/術・貫型(煌)/隠し(絲) は00b §4の値を使用。
- 召喚コストは全式神25、維持は2〜4/s(厳=2／玄・澪=3／燼=4)。式神は気ステを持たず、主人公の気プールを共有消費。
- **v1使役式神=玄のみ**。他5体の基礎ステ・契約章は00b §4。

### B2.5 装備補正

- 装備は**ステ加算 + 一部に倍率/特殊効果**を持つ(B3スロットに対応)。
- 加算系はB2.2の素値に直接合算。倍率系(会心倍率・属性ダメ+等)は計算式の該当係数に乗る。
- セット効果(同系統2点で追加バフ)はv1で軽く導入可だがopen question。

- 装備の正典(ID/価格/補正/付帯)は **00b §6.2 武具マスター**を参照。本書は反映規則のみ。

例(装備による実効ステ・武具名は00b §6.2):
`主人公Lv5(体26) + 呪具「桃の木剣」(体+8) + 装飾「火天の勾玉」(速+2・火属性ダメ+15%) → 実効 体34, 速+2, 火スキル×1.15`。会心倍率(critMul)系の上乗せも装飾で付与可。

### B2.7 ドロップ / 報酬

- 撃破報酬 = **EXP(主人公+式神分配) + 文(もん・B4) + ドロップアイテム**(通貨は文に一本化・銭は全廃)。
- ドロップ判定: 各行 `roll < rate` で個別判定(独立)。`qty`は `min..max`乱数。
- レアドロップは**保証カウンタ**でパリティ(同一レア未取得が一定回数で確定、運の偏り緩和)。v1は閾値20回で確定(open question)。
- 章ボス(喰い鬼)は固定ドロップ(進行=精製澱の結晶 + 確定装飾「鉄壁の勾玉」等・00b §5/§6.2)。
- **鎮魂で救済した敵は討伐ドロップと異なる(救済専用ドロップ＋該当敵は式神契約)。討伐選択時は報酬減＋穢増＋契約不可**(00b §2.4・§5の中ボス例参照)。
- クエスト報酬(B5)はこのドロップとは別経路(クエスト完了時に直接付与)。

### B2.9 穢ゲージ(新設・B2)

穢(けがれ)ゲージの正典仕様は **00b §2.3**。要点(値は00bが正):

- 範囲 0〜100。増加源=討伐 +5〜10／禁術 +15〜25／澱(hazard床)接触 +1〜3。減少源=鎮魂 −10〜20／浄め札・宿屋泊／休息。
- 段階デバフ: 平常(0〜39)なし／軽い穢(40〜69)気回復−25%／重い穢(70〜99)体・護−15%＋式神制御低下／暴走(100)行動制限。
- 終盤分岐は**最終穢値**を参照(闇祇戦フィナーレ演出が分岐)。穢は`save`に永続保持。

### B2.10 鎮魂コマンド(新設・コア体験)

鎮魂の正典仕様は **00b §2.4**。要点:

- 発動条件: **未練を持つ敵(中位/特定ボス)のHPが30%以下**で鎮魂窓が開く。
- 操作: 鎮魂発動 → 約**1.5sチャネル**(気を消費・主人公は無防備)。
- 成功: 救済(撃破＋追加報酬＋物語進行＋該当敵は**式神契約** or 良ドロップ)／穢 −10〜20。
- 討伐選択も可だが**穢増加・契約不可・報酬減**。
- ホットバーの「鎮魂」スロット(B7・00b §7.4の7番)に割当。

### B3.2 インベントリ構造

カテゴリ別の所持リスト(スタック対応)。UIはB7の固定枠 + ページ送り(webスクロールバー厳禁=デウス・コード教訓)で表示。

### B3.3 装備スロット(陰陽師の語彙)

主人公は**3スロット**(呪具1／装束1／装飾1)。式神は装備不可(v1)。スロット和名は00b §6.2の語彙(呪具＝武器・装束＝防具・装飾)に統一。

| スロット | 和名 | 装備種(例) | 主効果 |
|---|---|---|---|
| 武器 | 呪具(じゅぐ) | 笏 / 桃の木剣 / 霊符の杖 / 黒鉄の槌 | 体・術力・会心。攻撃挙動系統も決定 |
| 防具 | 装束(しょうぞく) | 狩衣 / 袍 | HP・護・呪抵抗 |
| 装飾 | 装飾(勾玉/守り) | 五行の守り / 白虎の守り / 火天の勾玉 等 | 速・属性ダメ倍率・critMul・特殊効果 |

- 呪具種は攻撃の**間合い/手数**に影響(笏=標準、杖=術力寄り、槌=範囲・低速)。攻撃挙動の差はB1スプライト/モーション要件と連動(主人公は符投げが基本・直接近接は無し)。
- 装着/解除はメニューで即時反映(戦闘外のみ。戦闘中の付け替え不可)。
- 同一スロットは1点のみ。装備変更すると旧装備はインベントリへ戻る(immutable: 新state生成)。

**第1章の装備具体値(ID/価格/補正/付帯)は 00b §6.2 武具マスターが正本**。旧B3の自前表(破邪の数珠/神楽扇/練りの狩衣/浄めの水干 等)は廃止し、00b §6.2の呪具(笏=初期/桃の木剣/霊符の杖/黒鉄の槌)・装束(白の狩衣=初期/蒼の狩衣/紅の袍)・装飾(五行の守り/白虎の守り/火天の勾玉/鉄壁の勾玉=喰い鬼ドロップ・取引不可)へ統合する。本書は重複表を持たない。価格は文・売値=floor(買値×0.5)。

### B3.4 所持上限

| 区分 | 上限(仮) | 超過時挙動 |
|---|---|---|
| 装備品スロット数 | 60種 | 満杯時は取得不可警告 → 拾得保留 or 自動売却(設定) |
| 消費アイテム種 | 40種 | 同上 |
| 素材種 | 60種 | 同上 |
| 進行アイテム | 無制限 | 破棄不可 |
| 1スタック上限 | 札/薬=99, 素材=999 | 超過分は別スタック or 取得不可 |
| 所持文(もん)上限 | 999,999 | 超過分は切捨て(00b §1) |

- 上限超過時は**ドロップを地面保留(光柱表示)**にし、整理後に再取得できる猶予を設ける(取りこぼしストレス軽減)。

### B3.5 消費アイテム(札・薬)

**消費アイテムの正典(ID/効果/価格/maxStack)は 00b §6.1 が正本**。旧B3の自前表(回復札/呪力丸/解毒札/破魔札/退魔札)は廃止し、00b §6.1へ統合する(回復→傷薬/上傷薬・気回復→気付け丸・状態1種解除＋穢浄化→浄め札・呪詛/封解除→解呪札・被ダメ軽減→守り札・帰還→戻り札)。本書は重複表を持たない。

- クイック札スロット(B1の`Q`／ホットバー8番・00b §7.4)に1種を割り当て可能。戦闘中の即時使用はこのスロット経由。価格は文・売値=floor(買値×0.5)。

### B3.6 受け入れ基準(B3)

- [ ] 4カテゴリ(装備/消費/素材/鍵) + 文(もん)でインベントリが構造化されている。
- [ ] 装備3スロット(呪具/装束/装飾・00b §6.2)に着脱でき、ステがB2.5の合算規則で反映される(HIT/EVA無し)。
- [ ] 戦闘中は装備変更不可・クイック札のみ使用可。
- [ ] 所持上限超過時にドロップが地面保留され取りこぼさない。
- [ ] スタック上限・売却不可フラグ(進行/装備中・00b `sellable:false`)が機能する。
- [ ] アイテム/武具/消費品の値が00b §6を正として参照され、本書に重複表が無い。
- [ ] UIがB7の固定枠+ページ送りで、webスクロールバーを使わない。

## 未決事項(Open Questions)

1. **式神同時顕現数(縛枠)**: v1は1枠=1体固定(裁定確定)。v2で複数枠・2体同時(隊列・連携技)を入れるか。入れる場合の気維持コストと判定負荷の上限は要検証。
2. **式神の進化/覚醒**: 固定役割のままか、章進行で上位式神へ覚醒させるか。覚醒があるなら素材・条件設計が必要。
3. **式神専用装備**: 式神に「呪符」枠を持たせるか(B3拡張)。持たせると装備管理UIが複雑化。
4. **状態異常の蓄積型**: 即時付与のみか、蓄積ゲージ式(凍結・畏縮等)を追加するか。
5. **レア保証カウンタの閾値**: 仮20回。第1章プレイテストで体感調整。
6. **会心と手動回避の優先関係**: 【裁定で解決】HIT/EVAは廃止・命中100%固定・回避は手動i-frameのみ(00b §2.1)。会心はCRT率(本体)＋critMul(装備由来)。本項はクローズ。
7. **セット効果**: 装備2点セットボーナスをv1で入れるか。入れると装備テーブル設計が増える。
8. **ヘイトの可視化**: 守式神の挑発効果をプレイヤーがどこまで把握できるUIにするか(B7と要調整)。
9. **難易度設定**: 単一固定か、易/標準の2段か。ダメージ式の倍率係数で吸収する想定だがv1範囲は未定。
10. **EXP分配率(式神70%)**: 顕現時間比例にするか一律にするか。一律は単純だが「出さなかった式神も育つ」点の納得感を要検証。
