## 1. これは何のゲームか

平安朝の架空帝都「**京音都（きょうおんと）**」を舞台に、朝廷直属の呪術機関「**陰陽寺（おんみょうじ）**」の若き陰陽師が、式神を操り妖魔と戦う**和風ダークファンタジー・アクションRPG**。怪異の裏には宮廷の陰謀が潜む（二層構造）。1人用ブラウザゲームだが、大規模世界・多数NPC・クエストログなど**MMORPG風の見た目と構造**を持つ。

### 5.2 戦闘・ステータスの噛み合い（機械的＋要確認）

- **MP相当＝「気（き）」に一本化**。B1の「呪力＝MP」表記は全廃。
- **攻撃ステは物理＝「体」・呪術＝「術力」に分離**（呪力という曖昧語は使わない）。
- **HIT/EVA（命中/回避）は廃止**（アクションゆえ手動回避＝i-frameが支配）。**速（SPD）**は行動速度/クールダウン補正として存続。
- **会心＝CRT（率%、B2所有）＋ critMul（倍率、装備由来）**で所有を明記。
- **縛（ばく）＝v1は1枠固定**（同時召喚1体）。複数枠管理はv2。C2の「厳は縛枠を圧迫」等の複数枠前提記述はv2注記へ。
- **エンカウント＝同一シーン内のシンボル接触**（画面遷移を伴わない）。A3に「battleはfield内サブ状態」を明記。

### 5.3 新設仕様（鎮魂・穢）

- **鎮魂（ちんこん）コマンド**（B1へ新設）: 未練を持つ敵（中位/特定ボス）のHPが**閾値30%以下**で**鎮魂窓**が開く → 鎮魂を発動（約1.5秒チャネル・気を消費・主人公は無防備）→ 成功で**救済**（撃破＋追加報酬＋物語進行＋該当敵は式神契約）。発動せず**討伐**も可だが**穢が増加・契約不可・報酬減**。鎮魂と討伐の二択が本作の倫理的コア。
- **穢（けがれ）ゲージ**（B2へ新設）: 0〜100。増加＝討伐(+5〜10)/禁術使用(+大)/澱接触(+)。減少＝鎮魂(−10〜20)/浄め札・宿屋(−)/休息(−)。段階＝0-39平常／40-69軽い穢（気回復低下）／70-99重い穢（体・護低下＋式神制御低下）／100で一時暴走（行動制限）。終盤の分岐は最終穢値を参照。

### 5.4 三重定義の統合（データマスター化）

以下は §00b `00b-data-master.md` に単一表として集約する（裁定承認後に生成）。

- **アイテムマスター**（B3消費品 ⇄ B4品揃えの統合）: ID/名前/価格/効果を単一表に。名称はB4基準に寄せ、回復＝「傷薬/上傷薬」、気回復＝「気付け丸」、穢浄化＝「浄め札」、解呪＝「解呪札」、武器＝呪具（数珠/扇/杖系）、防具＝装束、装飾＝勾玉/守り に統一。
- **クエスト表**（B5の3本 ⇄ C4の5本）: **C4の5本を内容正典**（セリフ執筆済）とし、B5がフラグ/構造（ID/giver/条件/報酬/QUEST_STEP）を供給。フラグ名⇄ゾーンID（C5）⇄QUEST_STEPの対応表も新設。
