## 2. ステータス定義（正典）

主人公・式神・敵で共通スキーマ。MP相当は**気（き）**に一本化（「呪力＝MP」表記全廃）。攻撃は物理=体・呪術=術力に分離。HIT/EVAは廃止（手動回避i-frameが支配）。

### 2.1 ステータス列（正典8項目）

| ステ | 正典和名 | 略号 | 旧称（廃止） | 意味 | 影響先 |
|---|---|---|---|---|---|
| 体力 | HP | HP | — | 最大HP | 生存 |
| 気 | 気（き） | 気 | 呪力/MP/JURYOKU | 行動資源（召喚・維持・呪術・鎮魂） | スキル/召喚/鎮魂/RES派生 |
| 体 | 体（たい） | 体 | 攻/ATK（物理分） | 物理攻撃の基礎火力 | 物理ダメージ式の基礎 |
| 護 | 護（ご） | 護 | 防/DEF | 被ダメ軽減 | `100/(100+護)` |
| 術力 | 術力（じゅつりき） | 術 | 呪力（攻撃)/MAG | 呪術スキル威力倍率 | 呪術ダメージ式の基礎・スキル係数に乗算 |
| 速 | 速（そく） | 速 | SPD | 行動速度・CD補正・攻撃後隙短縮 | 移動/隙/CD |
| CRT率 | 会心率 | CRT | critRate | 会心発生率（%・所有=本ステ） | 会心判定 |
| critMul | 会心倍率 | critMul | — | 会心時ダメージ倍率（所有=装備由来） | 会心ダメージ |

- **廃止**: HIT（命中）/ EVA（回避）/ 呪抵抗RES（→気からの派生値としてのみ存続、独立ステではない）。
- **派生**: `移動速度 = baseMoveSpeed × (1 + 速/200)`、`攻撃後隙 = base × (1 − 速/300)`、`呪抵抗 = floor(気/10) + 装備`。
- 実効ステ = 素値（Lv成長） + 装備補正 + バフ/穢デバフ。素値はimmutable保持、実効は都度計算。
- **会心の所有明記**: CRT率は本体ステ（基礎5%・Lv緩成長 `5 + 装備`）、critMul は装備由来（基礎1.5）。

### 2.2 ダメージ計算式（正典）

```
物理基礎 = 体  × skillMul       // 符・物理技
呪術基礎 = 術力 × skillMul       // 呪・属性技
防御後   = 基礎 × (100 / (100 + 護))
属性後   = 防御後 × elemMul      // 0.85 / 1.0 / 1.25（§3）
会心後   = 属性後 × (会心なら critMul else 1.0)   // 会心率=CRT%
最終     = max(1, floor(会心後 × random(0.95, 1.05)))
```
- skillMul: 符（通常遠隔）=1.0、呪術=1.4〜3.0、式神技=役割依存。
- HIT/EVA判定は無し。被弾回避はプレイヤーの手動i-frameのみ（命中100%固定）。

### 2.5 主人公の手段（正典・式神オンリー）

主人公は**直接近接で殴らない**。手段は以下のみ:
- **符（ふだ）**: 遠隔の基本攻撃（旧B1「通常攻撃3段コンボ」は符投げへ再定義。skillMul=1.0・気消費なし）。
- **呪（じゅ）**: 詠唱スキル（気消費・術力依存・個別CD）。
- **式神**: 召喚／切替／指揮（縛=v1は1枠固定＝同時召喚1体。複数枠はv2）。
- **鎮魂**: §2.4。
- 方向数=4（down/left/right/up、右=左反転flipX）。8方向は撤回。カメラ仰角=30°固定。

## 3. 五行相性表（正典・唯一基準）

| 関係 | 並び | 倍率 |
|---|---|---|
| 相生（与ダメ減・不利方向） | 木→火→土→金→水→木 | ×0.85 |
| 相克（攻撃側が有利） | 木→土→水→火→金→木 | ×1.25 |
| 無関係/同属性 | — | ×1.00 |

相克マトリクス（行=攻撃属性, 列=防御属性, 数値=elemMul）:

```
        木     火     土     金     水
  木 [ 1.00, 0.85, 1.25, 1.00, 1.00 ]
  火 [ 1.00, 1.00, 0.85, 1.25, 1.00 ]
  土 [ 1.00, 1.00, 1.00, 0.85, 1.25 ]
  金 [ 1.25, 1.00, 1.00, 1.00, 0.85 ]
  水 [ 0.85, 1.25, 1.00, 1.00, 1.00 ]
```

- 各敵の「弱点」は**この相克を唯一基準に決定**（弱点 = その敵の属性に×1.25で克つ攻撃属性）。
- 特（無属性・特殊）は五行相性を受けない（高火力＋鎮魂で対処）。
- 玄=木/風は五行上「木」として相性計算。風は演出/牽制属性で倍率非関与。

## 8. 整合チェック（解消した矛盾の要点）

- **式神名**: B2別系統名（火喰鬼/土塊狗/紙縒狐/護童子/影鵺）→ 玄/燼/澪/厳/煌/絲へ統一（§4）。
- **通貨**: 銭 → 文へ一本化（§1）。
- **アイテム三重定義**: B3/B4の重複名（回復札・霊鈴・呪力丸・解毒/破魔/退魔札・破邪の数珠等）→ 傷薬/上傷薬/気付け丸/浄め札/解呪札/呪具・装束・装飾へ統合（§6）。
- **クエスト本数**: B5の3本 ⇄ C4の5本 → C4の5本を内容正典に統一（§7）。
- **敵ステ ⇄ Lv曲線**: 03の仮値を06のLv曲線で撃破時間が妥当な値へ再スケール、弱点を相克に再判定、第1章雑魚を5種に統一、章ボス弱点窓から澪要求を除去（§5）。
- **ステ語彙**: 呪力/MP→気、攻→体、呪力(攻)→術力、HIT/EVA廃止、CRT率＋critMulの所有明記、穢ゲージ・鎮魂を新設（§2）。
