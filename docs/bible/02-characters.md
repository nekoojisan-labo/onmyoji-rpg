## 0. 目的 / スコープ

### 0.1 目的
- C1 名簿の各キャラを、2.5Dビルボードで「絵に描ける」具体描写・性格・背景/動機・口調/一人称・関係性・戦闘役割まで一意に確定し、C3(敵図鑑)・C4(セリフ)・C6(アセット生成)が矛盾なく参照できる単一の人物真実を提供する。

### 0.2 スコープ
- **含む**: 主人公 / 陰陽寺の師・上役(2名) / 主要式神(6体) / ライバル(1名) / 主要NPC(4名) / 人間の敵=黒幕(2名)。各キャラの外見・性格・背景/動機・口調/一人称・関係性・戦闘役割(該当時)。式神は性質/属性/見た目を含む。
- **含まない**: ステータス数値(B1/B2)・行動パターンやAI(C3/B1)・セリフ全文(C4)・スプライト切り出し命名規則(C6)。本書はそれらが参照する「人格・声・絵」の真実だけを定める。

### 0.3 ビルボード設計の前提(デウス・コード教訓の反映)
- 全キャラは **2D板ポリゴン(カメラ正対ビルボード)**。3Dモデルは作らない。
- スプライト一貫性が最大リスク(C1§7・デウス教訓)。そこで本書は各キャラに **方向数(後述§0.4)** と **配色3〜4色のパレット定義** を必ず付け、C6が「同一キャラと判別できる」ことを保証する識別子(髪色/装束主色/特徴小物)を最低3点ずつ固定する。

### 0.4 ビルボード方向数の確定(スプライト一貫性リスクの直視)
| 種別 | 方向数 | アニメ | 理由 |
|---|---|---|---|
| 主人公(凪沙) | 4方向(前/後/左/右。右は左の反転) | 待機2F・歩行4F・呪文詠唱2F・被弾1F | 操作キャラのみ最大密度。アイソメ4方向で十分(右=左反転で実質3枚) |
| 戦闘する式神(6体) | 2方向(左右。前後は同絵を流用) | 待機2F・攻撃2F・被弾1F | 召喚物は被写体が小さく方向減でも破綻しにくい |
| 戦う敵/ボス(C3管轄だが造形はここで規定) | 1〜2方向 | 待機2F・攻撃2F | 正対固定で量産性優先 |
| 会話NPC(非戦闘) | 1方向(正面立ち絵)＋表情差分 | 表情3種(通常/喜/憂) | 会話のみ。歩行スプライト不要 |

- **原則**: 「動かないキャラほど方向を減らす」。歩行アニメの一貫性地獄を、操作キャラと召喚式神に限定して封じ込める。
- **方向数の正典(00 §5裁定)**: 操作・移動キャラの方向数は **4(down/left/right/up)。右=左の反転(flipX)** で生成。8方向は撤回。「右に別テクスチャ＝反転無し」の記述は撤回(=反転で運用)。本表の主人公4方向はこの裁定に一致。式神2方向(左右)・敵1〜2方向は被写体が小さく移動主体でないための量産配慮で、いずれも左右は反転flipXで足りる。

## 1. 主人公

### 1.1 凪沙(なぎさ)
C1§4.1準拠 / 17歳 / 姓なし(陰陽寺に拾われた孤児) / 正道派見習い / 師=賀茂玄旨の唯一の直弟子 / 性別表現=中性的固定。

#### 外見(ビルボード用・具体)
- **背格好**: 細身で中背。少年とも少女とも取れる中性的な輪郭。腰位置高めで動きが軽い印象。
- **髪**: 漆黒のショート〜あご下のミディアム。後ろで小さく束ねた**みづら風の細い垂髪**を左右に一房。前髪は眉で切り揃え、片目にかかる房が一筋(影を演出)。**髪飾り＝白い紙垂(しで)を結んだ細紐**(陰陽寺見習いの証・特徴小物①)。
- **装束**: 陰陽道見習いの**白×藍の狩衣(かりぎぬ)崩し**。上は生成り(きなり)の白、袖口と襟に**藍鼠(あいねず)**の差し色。下は動きやすい括り袴の**濃藍**。足元は**黒の足袋＋草鞋(わらじ)**。
- **特徴小物**: ①紙垂の髪紐 ②腰に下げた**呪符の束(白い短冊が数枚扇状)**＝特徴小物② ③首から下げた**翡翠色の勾玉(まがたま)**＝特徴小物③(家族の形見・物語の鍵に絡む)。
- **配色パレット(C6固定・4色)**: 生成り白 `#efe9dc` / 濃藍 `#26334d` / 藍鼠 `#5f6b78` / 翡翠 `#3a8f73`。肌は中間トーンで性別を曖昧に。
- **表情差分(会話用)**: 通常(凛とした半目)/ 動揺(眉寄せ)/ 決意(見開き)。
- **アニメ**: 待機(紙垂が揺れる2F)・歩行4F・**詠唱(両手で印を結び符が浮く2F)**・被弾。

#### 性格
- 表向きは**快活で物怖じしない**。市の子どもにも妖魔にも同じ目線で話す。
- 芯は**強い喪失感と「聴きすぎる」優しさ**。妖魔の未練まで聴き取ってしまうため、討つことに常に痛みを伴う。これが「鎮魂」を選ぶ動機の感情的核。
- 危ういのは**他者の業に共感しすぎて呑まれかける**点(C1の穢ゲージと直結)。

#### 背景 / 動機
- 幼少時、右京の怪異(自然発生の怨霊)で家族を失い、玄旨に拾われた。家族の死因が後に「人為怪異」と繋がる伏線を持つ(終盤、黒幕の澱精製と無関係でないと示唆可)。
- 稀有な才「**真名を聞く耳**」(C1§4.1)を持つ。妖魔の未練を言葉として聴ける唯一の存在。だからこそ鎮魂・契約ができ、黒幕の「澱を縫合した人工怪異」が**未練を持たない=聴こえない**ことに気づける(=人為発見の感覚的トリガー)。
- 動機の推移: 「家族を奪った怪異を祓いたい(復讐に近い)」→「怪異の声を聴くほど憎めなくなる」→「都の澱そのものを鎮めたい(救済へ昇華)」。C1の核心テーゼをキャラ単位で体現。

#### 口調 / 一人称
- **一人称＝「わたし」**(ひらがな表記で固定。中性を保ち、性別を明示しない)。
- 二人称: 親しい相手「君」、目上「あなた」、妖魔「お前」だが憎悪は乗せない。
- 文体: 普段は砕けて快活(「〜だよ」「〜でしょ」)。鎮魂の場面・対妖魔では**急に静謐で詩的**になる(声色が変わる演出。C4が二層の語彙を用意)。決め台詞の雛形「**聴かせて。あなたの本当の名を**」(契約・鎮魂時の共通フレーズ・C4で確定)。

#### 関係性
- 師 **賀茂玄旨**: 親代わりにして最重要の絆。終章の喪失が物語の重心。
- 同期 **桔梗**: 心を許せる唯一の同世代。漫才的な軽口が日常パートの息抜き。
- ライバル **藤宮縹**: 才を妬まれ見下される→後に共闘。理念の対立(救済 vs 兵器)が軸。
- 初期式神 **烏天狗・玄**: 相棒第一号。軽口を交わせる式神。

#### 戦闘上の役割
- **本人は直接近接で殴らない**(00 §5「式神オンリー」確定)。手段は **符・呪＋式神指揮＋鎮魂**の4種のみ(00b §2.5):
  - (1)**式神**の召喚/切替/位置指示(v1は縛1枠固定=同時召喚1体・切替制。複数枠はv2)。
  - (2)**符(ふだ)**: 遠隔の基本攻撃(気消費なし)。旧「通常攻撃3段コンボ」は符投げへ再定義済(00b §2.5)。
  - (3)**呪(じゅ)**: 詠唱スキル(気消費・術力依存・個別CD・自衛/攻撃)。
  - (4)**鎮魂**: 未練を持つ敵のHPが **30%以下** で鎮魂窓→約1.5秒チャネル(気消費・無防備)→救済で討伐or契約を選ぶ(00b §2.4)。
- 弱点: 単体では脆い。**式神を失うと符と自衛の呪のみ**となり危機。v1は縛1枠固定のため召喚体の温存・切替判断が緊張感を生む(数値は00b)。

## 2. 陰陽寺の師 / 上役

### 2.1 賀茂 玄旨(かもの げんし) — 師・正道派の長
C1§4.2準拠 / 老練な陰陽師 / 鎮魂を説く / 玄冥の旧友で禁忌派にいた過去(伏線) / 終章で物語の核。

#### 外見
- **70歳前後の老翁**。痩身長躯で背は曲げず、静かな威厳。
- **髪/髭**: 総白髪を高く結い、長い白髭。眉も白く長い。
- **装束**: 陰陽寮上位を示す**黒の浄衣(じょうえ)に金茶(きんちゃ)の袈裟風帯**。胸に北斗を象った刺繍。手に**錫(しゃく)を兼ねた古びた杖**(特徴小物①)。腰に**鎮魂の鈴(ちんこんのすず)**(C1§1.3象徴物・特徴小物②=終盤鍵アイテムの保有者)。
- **配色パレット**: 墨黒 `#1c1b1f` / 金茶 `#9c7a3c` / 白(髪髭) `#e8e6df` / 朱(瞳の差し) `#9c3a2e`。
- **特徴**: 右目に古い傷(禁忌派時代の代償・無言の過去の証)。立ち絵は1方向＋表情(通常/憂い/瞑目)。

#### 性格
- **穏やかで多くを語らない**。問いに問いで返し、答えを弟子に「聴かせる」教育者。
- 内に**贖罪の重さ**を抱える。かつて澱の研究に手を染めた過去(C1§2「師の真相」)への自責が、鎮魂理念への執着になっている。

#### 背景 / 動機
- 若き日、玄冥と共に禁忌派で澱の研究を行った。ある実験で人を犠牲にしかけ、袂を分かった(右目の傷はその時のもの・C4で詳細)。以後、討伐より**救済**を貫くことで贖い続けている。
- 動機: 「自分が育てた術が都を蝕んだなら、自分の弟子の手で正されるべき」。凪沙を後継に選んだ理由はその才(真名を聞く耳)と、自分にない「他者の業を憎まず聴ける心」。

#### 口調 / 一人称
- **一人称＝「わし」**。二人称「お前さん」「凪沙」。
- 文体: ゆったりと古雅。比喩と問い返しが多い(「祓うてどうなる。澱はまた湧く。…ならば、どうする?」)。叱責は静かに短く。

#### 関係性
- 凪沙: 父にして師。**終盤、凪沙を庇って逝く**(00 §5裁定で確定)。死の演出強度(完全死亡/看取り)のみC4/B6裁量。
- 玄冥: 旧友にして最大の対(つい)。憎しみと哀しみが同居する関係。終盤、二人の対話が物語の主題を言語化する。
- 土御門実勝(長官): 上司だが理念が合わず、冷遇される側。

#### 戦闘上の役割
- **基本は非戦闘(指南役)**。ただし第5章クライマックスで**一度だけ共闘/盾**として参戦(凪沙を庇う演出戦闘)。式神は使わず鎮魂の鈴と高位の呪のみ。C3/B1は「イベント戦闘の味方ユニット」として最小実装で扱う。

### 2.2 土御門 実勝(つちみかど さねかつ) — 陰陽寺長官(寺司)・実利派寄り
C1§4.2準拠 / 実利派寄り・朝廷=左大臣に近い / 中盤の制度的な壁 / 完全な悪人ではない保身的小役人。

#### 外見
- **50代の中肉中背**。なで肩で姿勢にやや緩み。
- **顔**: 丸顔、薄い口髭、愛想笑いの皺。目だけが笑っていない。
- **装束**: 官位を誇示する**朽葉色(くちばいろ)の正装束帯に過剰な装飾**。扇を常に手に(特徴小物①)。指に**翡翠と金の指輪**(賄賂趣味・特徴小物②)。
- **配色パレット**: 朽葉 `#7a5b2e` / 鈍金 `#b8942f` / 白 `#ddd6c4`。立ち絵1方向＋表情(愛想笑い/狼狽/不機嫌)。

#### 性格
- **事なかれ主義の保身家**。怪異より「醜聞が朝廷に露見すること」を恐れる。
- 悪意より**臆病と無責任**。だからこそ厄介(正面の悪役ではなく、正論を制度で潰してくる壁)。

#### 背景 / 動機
- 出世と家名維持が全て。左大臣・影道に取り入り、陰陽寺を「朝廷に都合よく」運営することで地位を保つ。
- 動機: 「波風を立てるな。怪異は粛々と隠して処理せよ」。凪沙の捜査が宮廷に及ぶと、保身から妨害する。終盤、影道の正体を知り**狼狽し小さく協力**する(完全な悪に堕ちない救い)。

#### 口調 / 一人称
- **一人称＝「私(わたくし)」**。二人称「君たち」。
- 文体: 慇懃で回りくどい官僚語。「〜というわけにはいかんのだよ」「立場というものがあってな」。

#### 関係性
- 凪沙/玄旨: 理念的に対立。表向き上司として接するが内心は厄介者扱い。
- 影道: 取り入る相手。利用されていると気づかない。
- 縹: 才あるエリートとして重用(実利派の旗手として)。

#### 戦闘役割
- **なし**(非戦闘NPC・1方向立ち絵)。

## 3. 主要な式神(6体)

> 名・読み・五行・役割・契約章は **00b §4 式神マスター(6体・正典)** に一致させる。本書は性質/見た目/性格/戦闘役割を深堀り。式神は**召喚物=手駒**で、凪沙の「縛」枠に収まる。全式神2方向ビルボード(§0.4)。
> **縛(同時召喚数)**: v1は **1枠固定(同時召喚1体)**。複数枠はv2(00 §5裁定)。よって厳など重コスト式神を「召喚すると他枠を圧迫」する記述はv2の複数枠前提であり、v1では「召喚中は他式神を召喚できない(切替制)」と読み替える。
> **式神ステ数値の正典**: HP/体/護/術力/速・召喚維持コスト等の数値は **00b §4** を正とする。本書は数値を持たず役割・性質のみ規定。
> **v1使役式神**: v1で実際に使役するのは **玄のみ**(燼は第2章契約・v1は登場演出のみ)。00 §5裁定に一致。
> 注: 玄=烏天狗の五行は **五行上は木に属し、表現属性として"風"を持つ**(相生相克は木で判定・00b §3。風は演出/牽制属性で倍率非関与)。

### 共通設計(全式神)
- 召喚演出: 凪沙が**依代(紙/面/骨片)**を投げ、淡い霊光と共に顕現。退場は霊光となって依代へ収納。
- 性格を持たせる理由: C4のセリフ供給＋プレイヤー愛着(収集要素の感情的報酬)。各式神に短い口調を設定。
- 見た目の統一規則: 全式神に**淡く発光する「式の輪郭線(藍白)」**を付け、妖魔(現実色)と視覚的に区別する(C6識別ルール)。

### 3.1 烏天狗・玄(からすてんぐ・げん) — 木(風)・初期式神
**契約章: 第1章** / 役割: 速攻・斥候・軽快な近接。

- **見た目**: 黒羽の若い烏天狗。漆黒の翼、赤い嘴の面風の顔、山伏装束の崩し(濃緑×黒)。手に**羽団扇(はうちわ)**と短い**錫杖**。背は凪沙よりやや高い細身。式の輪郭線=藍白に**緑の差し**。
- **配色**: 漆黒 `#1a1a1d` / 深緑 `#2f4a35` / 朱(嘴) `#a8392c`。
- **性質/属性**: 木(風表現)。風で間合いを詰める高速近接＋羽団扇の突風(ノックバック)。
- **性格**: 軽口で生意気だが忠実な相棒。凪沙をからかいつつ一番に守る。
- **口調/一人称**: 一人称「俺(おれ)」。「よっ、相棒」「遅いぜ、置いてくぜ」。
- **戦闘役割**: 序盤の主力近接。素早く弱く、手数で削る。チュートリアル式神。
- **関係**: 凪沙の最古の相棒。桔梗にも懐く。

### 3.2 火車・燼(かしゃ・じん) — 火・第2章
**契約章: 第2章** / 役割: 火力アタッカー・範囲焼却。

- **見た目**: 炎を纏う**猫車(火の車輪)に乗る半人半獣の鬼火**。体は灰黒、関節から橙の炎。額に一本角、長い火の尾。車輪は燃える法輪状。式の輪郭線に**橙赤の揺らぎ**。
- **配色**: 灰黒 `#2b2426` / 橙 `#d9621f` / 黄炎 `#e8a83c`。
- **性質/属性**: 火。範囲炎攻撃と継続ダメージ(燃焼)。木属性の敵に相生で強い。
- **性格**: 寡黙で激情型。怒りを内に溜め、解き放つ時だけ饒舌。
- **口調/一人称**: 一人称「我(われ)」。「…燃やす。それだけだ」。

### 6.1 左大臣・藤宮 影道(ふじみや かげみち) — 政治の黒幕

#### 性格
- 表: **完璧な紳士・人望ある名臣**。誰にも非の打ち所を見せない。
- 裏: **冷酷で傲慢、人を駒としか見ない**。怪異も縹も玄冥も道具。激昂すると貴族の薄皮が剥がれ醜い独占欲が露出。

#### 背景 / 動機
- 名門藤宮家の当主。摂関の座を狙い、政敵を「祟り」で次々失脚・抹殺。手段として玄冥に澱を集めさせ人工怪異を政敵に差し向けた。陰陽寺・実利派を金と地位で抱き込み捜査妨害。
- 最終目的: 鬼門を破り**鬼門の主**を呼び、その力で都の絶対的支配者になること。玄冥を「便利な術師」と侮り、利用し尽くすつもり。

#### 口調 / 一人称
- **一人称＝公の場「私(わたし)」/ 本性「この私」**。二人称「君」「お前ごとき」。
- 文体: 普段は典雅で柔和(「これはこれは、陰陽寺の…ご苦労なことだ」)。本性露出時は冷たく傲然(「駒は駒らしく、盤上で果てよ」)。

#### 関係性
- 縹: 育てた甥にして駒。裏切られ激昂する。
- 玄冥: 利害一致の共犯。互いに踏み台と侮り、終盤決裂(C1§3.2)。
- 凪沙/玄旨: 邪魔者。最初は歯牙にもかけないが捜査が核心に迫り敵視。

#### 戦闘上の役割
- **第5章・中ボス**(玄冥戦の前段)。妖魔化した姿で対峙。澱の触手・藤蔓拘束・人工怪異召喚を行う(C3が具体化)。ここで**縹が寝返り共闘**(条件付き・§4.1)。

- 朝廷と玄旨への**冷えた復讐心**。感情を爆発させず、淡々と都を蝕む不気味さ。

#### 背景 / 動機
- 禁忌派最後の長老。かつて玄旨と共に澱を研究した旧友(C1§2)。禁忌派が朝廷と正道派に切り捨て解体された時、地下に潜伏し術を磨き続けた。
- 動機(二重・C1§3.2): (a)澱の精製術を極める純粋な探究欲 (b)自分たちを切り捨てた朝廷と、袂を分かった旧友・玄旨への復讐。影道の政治力は鬼門を破り**鬼門の主**を呼ぶための手段に過ぎない。最終的に自ら人外の高みへ至ることが目的。
- 玄旨との因縁: 「お前は逃げた。私は進んだ。どちらが真の陰陽師か、見せてやろう」。物語主題を体現する対話。

#### 口調 / 一人称
- **一人称＝「わたし」/ 古風に「老骨(ろうこつ)」**。二人称「玄旨」「小僧(凪沙)」。
- 文体: 静かで丁寧、それゆえ不気味(「…ふむ。よう澱が育っておる。美しいとは思わぬか、凪沙とやら」)。

#### 関係性
- 玄旨: 旧友にして宿敵。本作の核となる「分かれた二人の陰陽師」。
- 影道: 利用し利用される共犯。終盤決裂。
- 凪沙: 玄旨の弟子として観察対象。真名を聞く耳の才に興味を示す。
- 白狐・絲: 善悪の鏡像(光の九尾 vs 闇の九尾)。

#### 戦闘上の役割
- **第5章・章ボス＝ラスボス第一形態**。人外態で対峙。澱の縫合怪異召喚・呪詛・尾の薙ぎ払い・穢付与攻撃(C3)。撃破後、その澱が**鬼門の主・闇祇(やみつおおかみ)**の真ラスボス第二形態へ繋がる(闇祇本体の造形はC3管轄＝「都の全澱の集合体」とのみ本書は規定)。
